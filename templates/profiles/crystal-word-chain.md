Crystal Word Chain is a word game where the goal is to connect words using common two-word phrases or compound words (e.g. tea > tea time > time machine > machine learning, etc.). It uses a grid system into which the words are placed, so it's not a simple linear progression.

There are plans to create an alternative set of rules so that it can also be played as a glass bead game. Inspired by Hermann Hesse's classic novel, a Glass Bead Game challenges players to weave connections between all aspects of human knowledge. The idea is that players can gain new insights by synthesizing ideas across disciplines.
